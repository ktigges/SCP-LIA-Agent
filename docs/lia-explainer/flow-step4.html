4Retrieve evidence

Only once there's exactly one confirmed device or user, and one valid time window, does LIA start pulling actual data. And it only runs the tools it actually needs -- ask about sign-ins, and it's not also going to pull the full device activity history for no reason. There are four tools it can call here, depending on the question:

  • get_device_timeline -- builds a timeline of what a device did (processes run, files touched, network connections) during the window. Only runs when the question is about a device.
  • get_user_authentication_timeline -- builds a timeline of sign-ins and logons for a user during the window. Kept separate from device activity on purpose, so the two don't get mixed together in one list.
  • get_related_alerts -- pulls any security alerts tied to that device or user during the window, so an existing detection shows up alongside the raw activity instead of needing a second lookup.
  • match_observed_indicators -- takes IPs, domains, URLs, and file hashes that showed up in the results above and checks them against threat intelligence that was valid during that same window. This is what flags "this IP address is already known-bad," for example.

Example: ask "what did this laptop do yesterday afternoon?" and LIA calls get_device_timeline and get_related_alerts, then match_observed_indicators if anything worth checking turned up -- it skips the user sign-in tool entirely, since nothing about the question needs it.
