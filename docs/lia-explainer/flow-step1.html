1Analyst submits a request

One device or one user, a start time, an end time, and a timezone -- that's the whole ask. Nothing else is required, and nothing else is assumed.

If any of that's missing, or it's too vague ("check this machine recently"), LIA stops right here and asks for the specifics instead of running with a best guess. No defaults get filled in behind the scenes.
