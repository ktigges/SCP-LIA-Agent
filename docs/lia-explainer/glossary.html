Glossary

Quick plain-English lookups. No prior knowledge assumed.

TermWhat it means here
AI agentA chat assistant that's been given a specific job and a specific, limited set of tools -- instead of being free to do anything.
Microsoft Security CopilotMicrosoft's AI security product. The chat window, the underlying AI model, and the place where you can plug in custom agents like LIA.
MCP (Model Context Protocol)A standard way of handing an AI a fixed list of tools it's allowed to use -- and nothing outside that list.
KQLKusto Query Language -- the language used to search this log data. Like a very precise search bar. LIA's 8 searches are written once by a person and reused every time.
Advanced HuntingThe search feature inside the Microsoft Defender portal (a website). This is where a search actually runs.
Microsoft SentinelMicrosoft's larger log storage and correlation system. When it's connected to Defender, its data can also be reached through Advanced Hunting.
Defender XDRMicrosoft's security detection product line -- covers laptops, phones, identities, email. Supplies most of the device and alert data.
"Save as tool"The action of turning one written search into something the AI can call by name, filling in blanks -- it never sees the search text itself.
Agent manifestThe settings file that spells out LIA's instructions, which tools it's allowed to use, and how it should write the final report.
PluginThe settings file that tells Security Copilot where the approved searches live and which of them are allowed to be called.
SOCSecurity Operations Center -- the team of analysts LIA is built for.
UTCCoordinated Universal Time -- the one single timezone every search uses internally, so nothing gets mixed up by daylight saving or local time zones.
WorkspaceThe specific set of log data LIA is allowed to look at. One per deployment, chosen ahead of time.
