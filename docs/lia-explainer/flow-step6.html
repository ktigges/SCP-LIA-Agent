6Correlate

This is the one step where the model is actually reasoning, instead of just running a fixed query and reporting what comes back.

It's only allowed to connect two pieces of evidence if they genuinely share something concrete -- same device, same user, same IP address, same file, or a time overlap it can state in plain words. Anything looser than that gets labeled as an opinion, not a confirmed fact, in the report.

Example: a sign-in from an unusual IP address, and a file download three minutes later from that same IP -- that's a fair correlation, because the IP address is shared and the timing is close. Two unrelated alerts that just happen to fall in the same 10-hour window, with nothing else connecting them, are not correlated -- they're reported separately.
